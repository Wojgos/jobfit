# JobFit frontend

Angular 22 (standalone components, zoneless, signals) with NgRx Signal Store, Angular CDK
drag and drop and Tailwind CSS. See the [main README](../README.md) for the whole project.

```bash
npm ci
npm start          # http://localhost:4200, /api is proxied to the backend on :8000
npm test           # Vitest
npx ng lint        # angular-eslint, including template accessibility rules
npx ng build
```
